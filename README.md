# 出席オートパイロット (atpilot)

**OTP Autopilot** — 時間ベース OTP の生成・検証を行う技術実証用 Web ツール

[![Live Demo](https://img.shields.io/badge/demo-GitHub%20Pages-8b5cf6?style=flat-square)](https://4uthen7.github.io/atpilot/)
[![License](https://img.shields.io/badge/license-MIT-blue?style=flat-square)](#ライセンス)

## 概要

[出席オートパイロット](https://4uthen7.github.io/atpilot/) は、30 秒間隔で更新される 6 桁 OTP（ワンタイムパスワード）を**クライアント側で逆算・表示**し、学籍番号とともに出席 API へ送信する仕組みを、**セキュリティ研究および技術的検証**のために公開している実験プロジェクトです。

学校の出席システムが OTP 方式である場合、その生成ロジックがクライアントから再現可能かどうかを検証するための PoC（概念実証）です。本リポジトリは単体 HTML + Google Apps Script で構成され、GitHub Pages 上でホストされています。

> **本ツールは不利益をもたらすことを目的としたものではありません。**  
> あくまで OTP 実装の安全性評価・教育・技術検証を目的としています。

## 主な機能

実際の公開サイト（[4uthen7.github.io/atpilot](https://4uthen7.github.io/atpilot/)）で利用できる機能は以下のとおりです。

### 🔑 ライブ OTP 表示

- Unix タイムスタンプを 30 秒単位の `interval` に分割し、決定論的に 6 桁 OTP を生成
- 残り秒数タイマー・プログレスバー・現在の interval 番号をリアルタイム表示
- 画面上に OTP 生成アルゴリズムをそのまま公開（透明性のため）

```
interval = floor(unix / 30)
seed     = interval × 2654435761
OTP      = (seed >>> 0) % 900000 + 100000
```

### 📝 出席送信

- 学籍番号（7 文字、例: `24AK001`）を入力してワンクリック送信
- 形式バリデーション（入学年度 20–26、学科コード AK/AA/AS/AP、末尾 3 文字英数字）
- 送信時に現在の OTP・日付・時刻を学校側 GAS エンドポイントへ POST
- ブラウザ内の送信ログ（セッション内）を表示
- 学籍番号は `localStorage` に保存され、次回アクセス時に自動入力

### 👤 Google アカウント連携

- Google Sign-In（OAuth 2.0）によるログイン
- ログイン後、アカウントに紐づく**出席履歴**を表示（最大 100 件）
- プロフィール画像・表示名・メールアドレスを UI に表示

### 📋 ログ記録（Google Apps Script + スプレッドシート）

出席送信時、Google ログイン済みユーザーについて以下の情報をスプレッドシートに記録します（`gas_logger.gs` 参照）:

| カテゴリ | 記録項目 |
|----------|----------|
| 出席情報 | タイムスタンプ、学籍番号、日付、時刻、OTP |
| ネットワーク | IP アドレス（ipify API）、接続種別、下り速度、RTT |
| ブラウザ | User-Agent、プラットフォーム、言語、画面解像度、ウィンドウサイズ、ピクセル比 |
| 端末 | タイムゾーン、TZ オフセット、オンライン状態、Cookie 有効、CPU コア数、メモリ、タッチ対応 |
| Google | アカウント ID（sub）、メール、表示名 ※ID トークン自体は保存しない |

### 🤝 共有機能

- Web Share API またはクリップボードコピーでツール URL を共有
- 出席送信成功後に共有ポップアップを表示

## セットアップ（自己ホスト）

### 1. フロントエンド

```bash
git clone https://github.com/4uthen7/atpilot.git
cd atpilot
```

`index.html` を GitHub Pages や任意の静的ホストにデプロイします。

### 2. Google OAuth クライアント ID

1. [Google Cloud Console](https://console.cloud.google.com/) で OAuth 2.0 クライアント ID（Web アプリケーション）を作成
2. 承認済み JavaScript 生成元にデプロイ先 URL を追加
3. `index.html` の `GOOGLE_CLIENT_ID` と `gas_logger.gs` の `GOOGLE_CLIENT_ID` を同一値に設定

### 3. ログ記録用 GAS

1. Google スプレッドシートを新規作成
2. **拡張機能 → Apps Script** を開き、`gas_logger.gs` の内容を貼り付け
3. `SPREADSHEET_ID` を自分のスプレッドシート ID に変更
4. **デプロイ → 新しいデプロイ → ウェブアプリ**
   - 実行ユーザー: 自分
   - アクセス: 全員
5. 表示された URL を `index.html` の `LOG_GAS` に設定
6. 初回のみ `authorizeServices()` をエディタから実行し、権限を承認

### 4. 出席 API（学校側 GAS）

`index.html` 内の `GAS` 定数は、学校の出席受付用 Google Apps Script エンドポイントを指します。自己ホスト時は必要に応じて差し替えてください。

## セキュリティに関する注記

本プロジェクトは、**クライアント側で OTP が完全に再現可能であること**を示すことで、出席システムの OTP 実装が十分なセキュリティを持たないケースを可視化することを意図しています。

OTP アルゴリズムが公開されている以上、サーバー側での追加検証（端末情報、位置情報、ワンタイムトークン等）の必要性を議論するための材料として提供されています。
